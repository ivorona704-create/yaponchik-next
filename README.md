# Авто суши Япончик — четыре концепта сайта

Next.js 16 + TypeScript + Tailwind v4 + shadcn/ui. Одно меню на 202 позиции,
одна корзина с отправкой заказа в WhatsApp — и четыре разных визуальных мира,
из которых нужно выбрать один.

## Маршруты

| Путь | Что там |
|---|---|
| `/` | Хаб: четыре концепта, ссылки на аудит и демо переключателя |
| `/audit` | Аудит печатного меню: что мешает заказать и что чинит сайт |
| `/classic` | **Концепт 1 «Классика»** — самый первый сайт: логотип-маскот, песочная палитра, меню одним списком |
| `/moss` | **Концепт 2 «Мох»** — вечер в зале, прожектор по курсору |
| `/kaiten` | **Концепт 3 «Конвейер»** — лента кайтена, цвет тарелки = цена |
| `/sensei` | **Концепт 4 «Сэнсэй»** — манга, палочки вместо курсора, живой маскот |
| `/switcher` | Демо компонента `cinematic-theme-switcher` |

## Запуск

Нужен Node.js 20.9+ (стоит 24.19.0).

```bash
npm install
npm run dev
```

Откроется на `http://localhost:3000`. В `.claude/launch.json` этого проекта и
в `C:\Claude_projects\.claude\launch.json` настроен порт **3111** — там же
конфигурация для превью в Claude Code.

Проверки: `npm run lint`, `npx tsc --noEmit`, `npm run build`.

## Как обновить меню

Правится **только** `lib/menu.ts`. Пример позиции:

```ts
{ id: "r-philadelphia", name: "Филадельфия", desc: "рис, лосось, сыр, огурец",
  price: 480, weight: "8 шт", tags: ["hit"] }
```

| Поле | Что делает |
|---|---|
| `id` | уникальный ключ латиницей — по нему работает корзина |
| `name` | название блюда |
| `desc` | состав. Из него же строится картинка блюда |
| `price` | число → «480 ₽»; `null` → «цену уточните по телефону» |
| `variants` | несколько размеров: `[{ label: "33 см", price: 510 }, …]` |
| `weight` | вес или количество: `"250 г"`, `"3 шт"` |
| `pieces` | количество штук числом — для будущей подписи «· 8 шт» |
| `tags` | `"hit"`, `"new"`, `"spicy"`, `"baked"`, `"fried"` |
| `benefit` | только для сетов: выгода в рублях |

Контакты, часы, пороги бесплатной доставки и подарка, ссылка на Telegram —
объект `CONTACTS` в том же файле. Акции — массив `PROMOS`.
Лента хитов на всех концептах — массив `HIGHLIGHT_IDS`.

## Картинки блюд вместо фото

Нормальных фотографий блюд нет, поэтому каждая позиция рисуется по составу:

- `lib/ingredients.ts` — таблица «слово в составе → цвет слоя».
  «рис, лосось, сыр, огурец» даёт срез с тремя начинками;
- масаго и кунжут высыпаются по ободу, у жареных появляется корочка темпуры,
  у запечённых — шапка соуса;
- поворот зависит от хэша `id`, поэтому одинаковых картинок в меню нет;
- `components/shared/dish-glyph.tsx` рисует это в трёх стилях:
  `line` (золотая гравюра, «Мох»), `flat` (цвет, «Конвейер»),
  `ink` (тушь, «Сэнсэй»). Для суши, пончиков, сетов, пиццы, бургеров,
  коктейлей, соусов, напитков, салатов, горячего и десертов — свои формы.

Когда появятся настоящие фото, поле `photo` можно добавить в `MenuItem`
и подменять глиф картинкой.

## Темы

Переключатель — `components/ui/cinematic-theme-switcher.tsx`, работает через
`next-themes`. У каждого концепта свой `storageKey`, поэтому «Мох» помнит
вечер, а «Конвейер» — день:

| Концепт | storageKey | Тема по умолчанию |
|---|---|---|
| Классика | `yaponchik-classic` | `light` |
| Мох | `yaponchik-moss` | `dark` |
| Конвейер | `yaponchik-kaiten` | `light` |
| Сэнсэй | `yaponchik-sensei` | `light` |

Цветовые токены каждого концепта лежат в `app/globals.css` в блоках
`[data-concept="…"]` и `.dark [data-concept="…"]`. Концепт объявляется
атрибутом `data-concept` в своём `layout.tsx`.

В компонент переключателя внесены две правки: `aria-label` переведён на
русский, а на `setMounted(true)` стоит точечный `eslint-disable` — правило
`react-hooks/set-state-in-effect` из ESLint 9 ругается на штатную отметку
«смонтировано». Логика не тронута.

## Доступность и движение

- У каждого вау-эффекта есть спокойный вариант при `prefers-reduced-motion`:
  прожектор перестаёт плыть, конвейер превращается в обычную горизонтальную
  прокрутку со scroll-snap, палочки уступают системному курсору,
  счётчики выгоды показывают конечное число сразу.
- Палочки вместо курсора включаются только при `pointer: fine`.
- Состав блюда — 13 px с контрастом не ниже 4.5:1 в обеих темах.
- Все интерактивные элементы подписаны: у кнопки «+» есть `aria-label`
  с названием и ценой, у шкалы доставки — роль `progressbar`.

## Как получить ссылку для других людей

`localhost:3111` виден только на этом компьютере. Чтобы сайт открылся у
кого-то ещё, нужна статическая сборка:

```bash
npm run build:static
```

Готовые файлы лягут в `out/` (344 файла, ~9 МБ), рядом же собирается
`yaponchik-site.zip`. Дальше любой из вариантов:

- **Netlify Drop** — открыть https://app.netlify.com/drop и перетащить туда
  папку `out` или архив. Ссылка выдаётся сразу, без регистрации. Она временная,
  но для показа концептов этого хватает.
- **Vercel** — `npx vercel --prod` из папки `yaponchik-next`. Попросит войти
  через браузер, потом даст постоянный адрес и будет обновлять его по команде.

Важно: в экспорте пути к файлам абсолютные (`/_next/...`), поэтому сайт должен
лежать в корне домена. На Netlify и Vercel так и есть; открыть `out/index.html`
двойным кликом с диска не получится — нужен http.

## Публикация

Статический экспорт не нужен — подойдёт любой хостинг с Node (Vercel, Timeweb
Cloud, Amvera). Перед публикацией стоит сжать `public/interior.jpg` и сканы
меню (~660 КБ на троих) и завести карточки в Яндекс.Картах и 2ГИС — сейчас их
нет, а это бесплатный трафик.

Старый статический сайт остался в соседней папке `C:\Claude_projects\yaponchik`
и продолжает работать как запасной вариант.
